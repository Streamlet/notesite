# About notesite

Notes usually live in folders: projects, research, meeting notes, documentation. Publishing them often means exporting into a CMS, maintaining a second copy, or adopting a hosted editor.

notesite takes the other route: the folder is the site.

## Principles

- **Files are the source of truth.** Notes stay as Markdown, text, or HTML in normal directories.
- **No publish step.** Saving a note is enough; the server reads it.
- **Three templates.** A site needs an index, a category page, and a content page. Everything else is yours to design.
- **Small and local.** A single Go binary, no database, no required external services.
- **Your structure is navigation.** Folders become categories; filenames become URLs.

## What it is not

notesite is not a hosted writing service, a blog admin panel, or a database-backed CMS. It serves files you already own.

## This site

The site you are reading is generated by notesite from `note/sample`, using the templates in `template/sample`. The footer shows the engine version that rendered the page.
