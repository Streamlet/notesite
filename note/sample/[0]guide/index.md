# Guide

notesite has three moving parts: notes, templates, and configuration. This guide follows the shortest path to a running site, then explains the model and deployment.

- [Getting started](/guide/start) — build the binary, point it at the sample directories, and open the site.
- [Notes and URLs](/guide/notes) — file patterns, categories, resources, formats, and front matter.
- [Templates and assets](/guide/templates) — the three page templates, SSI partials, and static files.
- [Configuration](/guide/config) — the site, category, and resource settings.
- [Deployment](/guide/deploy) — release builds, Docker, sockets, and reverse proxies.

If you only read one page, read [Getting started](/guide/start).
