Guide

Getting started

Build the binary, point it at your notes, and open the site.

Why notesite

Notes stay notes. The site comes from them.

Your files, your format

Markdown, text, or HTML in ordinary folders. No database, no import, no export.

Three page templates

Index, category, and content. Customize the HTML and CSS, or start from the sample.

Live reload

Save a note or a template and refresh. The server picks up the change without a rebuild.

Categories and resources

Folders become navigation. Static assets live beside your notes and are served directly.

How it works

From folder to site in three steps.

  1. 01

    Write notes

    Use Markdown in folders. Add a .cat file to turn a folder into a category.

  2. 02

    Point the config

    Set note_root and template_root in site.toml.

  3. 03

    Run the binary

    Start notesite. The directory tree becomes the site; edits keep flowing.

Quick start

Run it in a minute.

Build with the version stamped in, then point the binary at the sample config.

VERSION=$(git describe --tags --exact-match 2>/dev/null || git rev-parse --short HEAD 2>/dev/null || echo dev)
go build -o notesite -ldflags "-X github.com/Streamlet/notesite/global.Version=$VERSION" .
./notesite --config=config/site.sample.toml
